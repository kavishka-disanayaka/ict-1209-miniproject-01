# 🍳 FlavorSync - Advanced Digital Recipe Book

**FlavorSync** is an interactive, frontend-driven digital recipe book designed to reduce food waste and simplify everyday cooking. It allows users to browse through a rich collection of recipes, filter by dietary requirements or cooking time, and contact the team directly.

---

## 🛠️ Tech Stack & Technologies Used

- **Markup & Structure:** HTML5
- **Styling:** CSS3, Bootstrap 5.3 (CDN)[cite: 1, 3]
- **Icons & Fonts:** Bootstrap Icons, Google Fonts (Fraunces & Plus Jakarta Sans)[cite: 2, 3]
- **Client-Side Logic:** Vanilla JavaScript[cite: 1, 3]
- **Version Control:** Git & GitHub

---

## ✨ Key Features (Frontend Phase 1)

- 🏠 **Interactive Home Page:** Includes a hero search section, category filters, popular recipes display, and a trending recipes carousel[cite: 3].
- 📖 **Comprehensive Recipe Collection:** Full recipe list page with dynamic client-side filtering by category, diet (Vegetarian/Non-veg), cook time, and difficulty[cite: 4].
- 🔍 **Real-time Recipe Search & Sorting:** Search recipes by name or keywords and sort them by popularity, rating, or cook time[cite: 4].
- 📩 **Dynamic Contact Form & FAQ:** Interactive contact page featuring real-time form validation, character counter, and toggleable FAQ accordions[cite: 2].
- 📱 **Fully Responsive Design:** Seamless user experience across mobile, tablet, and desktop devices built with Bootstrap 5 grid and custom CSS[cite: 1, 3, 4].
